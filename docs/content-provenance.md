# Initial editorial archive

Four genuine @githubsignals posts were checked against their public Instagram page metadata and their linked GitHub repository on 2026-09-26. `content/projects.json` holds concise editorial summaries; migration 004 imports the same records once. The application uses the checked-in collection until a database is connected, then uses the database exclusively. Admin changes never silently fall back to the seed.

This is a **selected archive**, not a complete or automatically synchronized Instagram feed. No follower count or engagement count is synthesized. We do not copy remote thumbnails or video files; each item links to the original post. Profile count was approximately 49K on the inspection date.
